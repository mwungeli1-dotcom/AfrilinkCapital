# Afrilink Capital

Afrilink Capital is a marketplace connecting African buyers with Chinese/global suppliers.

Business model:
- Customers browse products
- Customers submit requests
- Admin reviews requests
- Admin sources suppliers
- Admin sends quotations
- Customer pays deposit
- Afrilink orders and tracks delivery

Current stack:
- Frontend: Next.js App Router
- Styling: TailwindCSS
- Backend: Express.js
- Database: MongoDB
- Frontend hosting: Vercel
- Backend hosting: Render

Main features needed:
- Product marketplace
- Admin product upload
- Buyer requests
- Quotations
- Order tracking
- WhatsApp contact
- AI assistant later
